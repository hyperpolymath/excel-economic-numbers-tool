== Common Tasks

=== Building the Project

[source,bash]
----
cd .build/
just build           # Build all platforms
just build-excel     # Build Excel add-in only
just build-libre     # Build LibreOffice extension
----

=== Running Tests

[source,bash]
----
deno test            # Run Deno/AffineScript tests
just test            # Run all tests (Julia + Deno)
----

=== Development

[source,bash]
----
just dev             # Start development servers
just watch           # Watch mode for auto-rebuild
----
