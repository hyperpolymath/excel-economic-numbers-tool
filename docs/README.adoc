== Documentation Standards

=== File Formats

* **AsciiDoc (`.adoc`)**: Complex documentation, preferred format
* **Markdown (`.md`)**: Simple docs, GitHub compatibility

=== SPDX Headers

All documentation files must include:

[source,asciidoc]
----
// SPDX-FileCopyrightText: 2024-2026 Hyperpolymath Contributors
----

=== Document Structure

1. **Title** (level 1 heading)
2. **Brief description**
3. **Table of contents** (for long docs)
4. **Content sections**
5. **Links to related docs**
6. **Last updated date**
